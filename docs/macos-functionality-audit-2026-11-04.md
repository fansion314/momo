# macOS 服务模式功能检查（2026-11-04）

检查基线：客户端 `7aefaf12`，内核工作区 `6aa8918d`。本记录描述源码检查和本地回归，不代表已发布或已替换用户当前安装。

## 来源与回退范围

- `4ee97dd2`（2026-10-30）新增 macOS 特权服务。在 `macos-snapshot.ts` 移除 TCP/TLS 控制器、WebUI、secret 和 shell hook 字段；当时 Go helper 也使用核心 API 白名单。
- 配套内核的 `25f67b5e` 增加 `--momo-managed`，在配置解析、控制器创建和 updater 中再次限制公共控制器、WebUI 下载、内核替换等。
- `d8324831`（2026-11-03）与内核 `f72907b4` 回退的是 tizi 订阅/账户/策略实现，保留了 macOS 特权服务。客户端快照只取消了对 CORS 字段的删除，没有恢复 TCP 控制器或 WebUI。
- `838c75fd`（2026-11-03）将 helper 迁移到 Rust。Go 的 `r.URL.Path` 已解码，Rust 的 `Uri::path()` 仍包含百分号编码；照搬“拒绝百分号”检查后，正常的中文、空格和 Emoji 名称都会被拒绝。
- 当前客户端保留的 `tizi-managed` 检查用于迁移旧配置；没有活动的 tizi 页面或账户策略实现。当前内核 Go 源码未检出 tizi 实现。不能把保留的 macOS 服务模式等同于 tizi 订阅模式。

## 确认的功能缺陷与本次修复

| 操作                      | 原因与影响                                                           | 本次处理                                                               |
| ------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 切换节点                  | `/proxies/{group}` 的编码名称被拒绝                                  | 校验每段合法编码与危险路径，接受中文、Emoji、空格                      |
| 节点/分组测速、Smart 权重 | 同一检查影响 `/proxies`、`/providers/proxies`、`/group` 的编码参数   | 一并修复                                                               |
| 中文名称的订阅资源更新    | Provider API 同样被拦截                                              | 一并修复                                                               |
| 取消节点固定              | 白名单漏掉 `DELETE /proxies/{group}`                                 | 补全方法                                                               |
| 禁用规则                  | 漏掉 `PATCH /rules/disable`                                          | 补全路由                                                               |
| 清理 Smart 缓存           | 漏掉 `/cache/smart/flush` 及指定组路径                               | 补全路由                                                               |
| WebUI 状态存储            | 漏掉 `/storage/{key}` 的读写删除                                     | 补全路由                                                               |
| 远程控制端口              | 快照和内核两层强制移除配置，设置仍然显示可用                         | 普通用户进程提供 TCP 监听、密钥认证、CORS 与 HTTP/WebSocket 转发       |
| 内置 WebUI 下载和更新     | helper 禁止 `/upgrade/ui`，内核 updater 也禁用；原客户端没有替代实现 | 应用内更新操作改由普通用户下载 ZIP 并替换面板，应用提供 `/ui` 静态资源 |
| 操作失败无提示            | 切换请求异常未处理，设置应用失败仅写控制台                           | 显示错误；节点已切换但关闭旧连接失败时仍刷新选中状态                   |

普通用户控制器在服务内核就绪后启动，热重载时重新应用配置，内核停止或应用退出时关闭；关闭时主动断开 WebSocket 并释放端口。公开密钥与本地 helper session 分开，浏览器 Origin、Cookie、Authorization 和伪造 session 不会直接透传到 helper。转发目标固定在 `/core`，不能借此调用 helper 的安装、网络或生命周期接口。

## 后续完整修复

本轮目标版本：Clash Momo `2.0.4-8`（macOS r8），配套 Mihomomo `1.19.33-5`（内核修复提交 `843abbe5`）。

| 原检查项             | 最终实现                                                                                                                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TLS/Unix 控制器      | 普通用户进程支持 TCP、HTTPS/WSS 和 Unix socket；读取用户证书及密钥，支持客户端证书校验，Unix socket 0600，并处理停止清理及端口冲突                                                                                  |
| 外部面板管理         | `/restart`、`/upgrade/ui`、`PUT /configs` 由应用处理；配置在普通用户下读取和验证，再通过快照提交；`/upgrade` 使用 Homebrew 更新并沿用原生授权更新受保护副本。生命周期操作在响应发送后继续，避免连接先被自身重启断开 |
| GeoData/模型维护     | 内核恢复 managed 模式的 `/upgrade/geo`、`/upgrade/lgbm`；helper 补齐相应路由                                                                                                                                        |
| 目录外资源、符号链接 | 普通用户读取被配置引用的 Provider、证书和数据库，解引用后以普通文件导入受保护目录；root 不跟随用户链接。停止后按原映射回传内核更新，保留运行期间用户另外更改的文件                                                  |
| Smart 模型状态       | helper 直接查询运行副本的大小、修改时间和完整性；手动下载的状态仍查询刚下载的本地候选文件，重启后再显示实际运行副本                                                                                                 |
| 编码名称             | 允许 UTF-8、斜杠、反斜杠及百分号编码的名称作为路由参数，保留原 URI 转发；仍拒绝非法编码和控制字符、实际点路径。参数从不被用作 helper 的文件系统路径                                                                 |
| NTP 系统时间设置     | 配套内核不再覆盖显式 `write-to-system` 设置，默认值保持原内核行为                                                                                                                                                   |
| 启动钩子             | 复核后修正最初审计表述：应用的 `post-up` 启动方式是生成的就绪通知机制，服务模式已有等价就绪检测；订阅 YAML 的 `post-up/post-down` 本来就不是内核支持的 shell 配置。没有因此新增执行订阅脚本的功能                   |

特权服务自身仍只使用受保护 socket，二进制替换继续使用系统授权。这些是权限实现方式，公共控制器及应用操作已通过普通用户进程提供对应入口，不再静默移除可见设置。Tizi 保持撤回。
